ESP32 감지 펌웨어를 한 화면에서 시험합니다

Wavrel은 보드가 보고할 MQTT 허브를 직접 띄우고, 보드가 보낸 값을 한 콘솔에 모으고, 감지 결과를 사람이 실제로 지나간 기록과 맞춰 봅니다. 시뮬레이터 값과 실측 값은 끝까지 섞이지 않습니다.

브라우저에서 데모 열기 GitHub에서 소스 보기

데모는 설치 없이 내장 시뮬레이터로 돌아갑니다. Windows용 데스크톱 앱은 Microsoft Store 심사 중입니다.

보드가 보는 것을 방 안에 그려 줍니다

3D 화면은 와이파이 링크마다 감지 영역을 바닥에 그리고, 최근 14초의 움직임 점수를 링크 위에 띠로 세웁니다. 블루투스 노드와 추적 중인 기기도 같은 방에 나옵니다.

보드마다 펌웨어 하나, 고치지 않고 그대로

펌웨어는 각자의 웹 설치기로 올리고 MQTT로 보고합니다. Wavrel은 펌웨어를 담거나 고치지 않고 메시지 단계에서 묶습니다. 앱을 켜면 허브도 같이 켜지고, 첫 화면은 허브 비밀번호 하나만 묻고 보드마다 넣을 값을 보여 줍니다.

느낌이 아니라 검증으로

검증 세션은 사람이 링크를 실제로 지난 순간을 기록하고, 펌웨어가 감지한 구간과 맞춰 봅니다. 정답은 손에 쥔 키, PIR 센서, 또는 데모에서만 시뮬레이터에서 옵니다.

세션이 끝나면 메시지 기록을 내보내 나중에 다시 재생할 수 있고, 세션마다 점수 곡선을 담은 HTML 리포트 한 장으로 넘길 수 있습니다.

알림은 휴대폰을 거쳐 안경까지

규칙이나 검증 세션이 짧은 문장 하나를 만들면, 받는 쪽은 MQTT 구독만으로 그 문장을 띄울 수 있습니다.

  1. 앱이 문장을 만듭니다링크에서 움직임이 시작되거나, 기기가 방에 들어오거나, 검증 세션에서 한 번 지날 때마다.
  2. 한 토픽으로만 나갑니다lab/out/notify에는 앱만 쓸 수 있고 보드는 읽기만 합니다.
  3. 휴대폰이 받습니다안드로이드 앱 Wavrel Relay가 같은 와이파이에서 받아 알림으로 띄웁니다.
  4. 로키드 안경에 뜹니다검은 바탕에 초록 글씨로 보여 주고, 정해진 시간이 지나면 닫습니다.

주의 · 시뮬레이션

거실 CSI: 움직임

점수 1.16 · 임계값 0.5

오후 9:41

안경에 뜨는 화면을 옮겨 그린 예시입니다. 렌즈에서는 검은색이 투명하게 보입니다.

휴대폰 앱은 CI의 안드로이드 에뮬레이터에서 Wavrel의 허브와 함께 시험했습니다. 실제 휴대폰과 안경에서는 아직 시험하지 않았습니다.

집 안 네트워크에서 열리는 앱이라 방어적으로 만들었습니다

  • 창은 샌드박스 안에서 앱에 들어 있는 파일만 열고, 검증된 호출 11개로만 시스템에 닿습니다.
  • 허브는 비밀번호를 요구하고 사설 주소에서 오는 연결만 받습니다. 로그인 실패, 연결 수, 메시지 크기에 한도가 있습니다.
  • 허브 비밀번호는 Windows 자격 증명 보호로 저장합니다.
  • 실행 파일은 Electron fuse로 잠그고, 빌드마다 의존성을 감사하고 Microsoft Defender로 검사합니다.
